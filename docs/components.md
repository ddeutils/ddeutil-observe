**File structure of this application**:

```text
- models

        - crud.py           <-- Operation between Schema & Model
        - models.py         <-- Model interface
        - routes.py         <-- API
        - schemas.py        <-- Schema interface
        - views.py          <-- UI with Jinja template
```
